# Guide utilisateur — Gamefolio

Ce guide explique comment utiliser **Gamefolio**, l'application qui vous permet de
parcourir un catalogue de jeux vidéo, de rechercher un titre et de gérer votre
compte. Il ne demande aucune connaissance technique.

> Astuce de lecture : les mots en **gras** correspondent à ce que vous voyez à
> l'écran. Chaque fonctionnalité est décrite sous forme d'étapes numérotées.

## Démarrage rapide

1. Ouvrez l'application dans votre navigateur (par défaut :
   `http://localhost:5173`).
2. Sur la page de connexion, cliquez sur **S'inscrire**.
3. Saisissez votre adresse email et un mot de passe (au moins 8 caractères),
   puis confirmez le mot de passe.
4. Cliquez sur **Créer le compte**.
5. Revenez sur la page de connexion, saisissez vos identifiants et cliquez sur
   **Se connecter**.

Vous arrivez sur l'accueil : le catalogue est prêt à être exploré.

## Créer un compte

1. Depuis la page de connexion, cliquez sur le lien **S'inscrire**.
2. Renseignez votre **adresse email**.
3. Choisissez un **mot de passe** de 8 caractères minimum.
4. Répétez le mot de passe dans le champ **Confirmer le mot de passe**.
5. Cliquez sur **Créer le compte**.

Si les deux mots de passe sont différents, un message vous invite à les corriger.
Si l'adresse email est déjà utilisée, un message vous le signale : connectez-vous
plutôt ou utilisez une autre adresse.

## Se connecter

1. Sur la page de connexion, saisissez votre **adresse email** et votre **mot de
   passe**.
2. Cliquez sur **Se connecter**.

En cas d'erreur, un message indique que les identifiants sont invalides : vérifiez
l'orthographe de l'email et le mot de passe.

## Parcourir le catalogue

L'accueil affiche deux zones :

- un bloc **Choix du moment** qui met un jeu en avant, que vous pouvez faire
  défiler avec les flèches ;
- la grille **Jeux populaires** qui liste les jeux disponibles.

Faites défiler la page pour voir l'ensemble des résultats affichés.

## Rechercher un jeu

1. Repérez la barre de recherche en haut de la page (icône de loupe).
2. Saisissez tout ou partie d'un titre ou d'un mot-clé.

Les résultats se mettent à jour automatiquement pendant la saisie. Si aucun jeu ne
correspond, le message « Aucun jeu ne correspond à ta recherche. » s'affiche.

## Filtrer par catégorie

1. Dans la barre latérale de gauche, repérez la section **Filtrer les jeux**.
2. Cliquez sur une catégorie (par exemple **Action**, **RPG** ou **Course**).

La liste se limite alors aux jeux de cette catégorie. Cliquez sur **Tous** pour
réafficher l'ensemble du catalogue.

## Changer le nombre de jeux affichés

1. En bas de la grille, ouvrez la liste **Jeux par page**.
2. Choisissez **6**, **12** ou **24**.

Le nombre de pages s'ajuste automatiquement.

## Naviguer entre les pages

1. En bas de la grille, cliquez sur **Suivant** ou **Précédent**.
2. Le numéro de page affiché, par exemple « Page 2 / 5 », indique votre position
   dans le catalogue.

## Changer le thème clair / sombre

1. En haut à droite, cliquez sur l'icône **⚙ (paramètres)**.

L'interface bascule entre le thème clair et le thème sombre. Cliquez à nouveau
pour revenir au thème précédent.

## Se déconnecter

1. Dans la barre latérale de gauche, en bas, cliquez sur **Se déconnecter**.

Vous revenez à la page de connexion. Tant que vous n'êtes pas reconnecté, le
catalogue n'est plus accessible.

## Référence rapide

| Action | Où la trouver |
| --- | --- |
| Créer un compte | Page de connexion → **S'inscrire** |
| Se connecter | Page de connexion → **Se connecter** |
| Se déconnecter | Barre latérale, en bas → **Se déconnecter** |
| Rechercher un jeu | Barre de recherche, en haut |
| Filtrer par catégorie | Barre latérale → **Filtrer les jeux** |
| Changer le nombre de jeux | Bas de la grille → **Jeux par page** |
| Changer de page | Bas de la grille → **Précédent / Suivant** |
| Changer le thème | En haut à droite → icône **⚙** |

## Questions fréquentes

**Je ne parviens pas à créer mon compte.**
Vérifiez que les deux mots de passe sont identiques et qu'ils font au moins
8 caractères. Si l'adresse email est déjà utilisée, choisissez-en une autre ou
connectez-vous.

**Je suis redirigé vers la connexion alors que j'étais connecté.**
Votre session a peut-être expiré. Reconnectez-vous avec vos identifiants.

**Le catalogue est vide.**
Le catalogue doit être alimenté sur le serveur. Contactez la personne qui gère
l'application.

**Aucun jeu ne s'affiche quand je recherche.**
Essayez un mot-clé plus court ou vérifiez qu'un filtre de catégorie n'est pas
actif. Cliquez sur **Tous** pour réafficher l'ensemble des jeux.

**Puis-je utiliser l'application sur mon téléphone ?**
L'interface est lisible sur petit écran, mais l'adaptation mobile n'est pas encore
finalisée.
