# Documentation d'authentification

La documentation officielle de l'authentification est désormais séparée en deux fichiers :

- [`authentification-cours-et-projet.md`](authentification-cours-et-projet.md) : théorie, cours et fonctionnement ;
- [`plan-migration-authentification.md`](plan-migration-authentification.md) : migration et organisation technique.

Le système actuel utilise `pwdlib[argon2]`, `PyJWT`, `OAuth2PasswordBearer` et `OAuth2PasswordRequestForm`.
